# Assistente Acadêmico

Aplicação web para geração e correção de documentos acadêmicos utilizando a API da OpenAI (GPT).

## Tecnologias

- HTML5
- CSS3
- JavaScript 
- Node.js
- Express
- API da OpenAI (GPT)

## Funcionalidades

- Geração de:
  - TCC
  - Artigos Científicos
  - Relatórios de Estágio
  - Trabalhos Acadêmicos
- Correção de textos e documentos
- Upload de arquivos (.txt, .docx e .pdf)
- Download do documento gerado
- Interface interativa em formato de chat
